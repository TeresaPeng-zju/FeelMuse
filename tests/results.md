# MVP 实测记录

2026-11-03，Codex CLI 0.163.0，macOS，Google Chrome 146。每个场景使用独立工作副本。检查点来自 CLI 的文件读取记录、页面操作和截图。可用[验收场景](acceptance.md)在自己的浏览器环境复测。

| 场景 | 实际运行与观察 |
| --- | --- |
| 从零设计 | 空项目中直接用中文提出田野录音官网需求，未显式点名 Skill。CLI 选中了 FeelMuse，读取交互规则，给出地图与手记的具体取舍，等待选择。测试者给出地点索引方向后，CLI 做出了可直接打开的页面。Chrome 验证了地点切换、搜索、无结果、恢复、键盘选择，320–1440 像素宽的测试视口无横向溢出。录音明确标记为占位。 |
| 多参考设计 | 在 Chrome 中打开仓库内两份自制参考页，操作正反向滚动并检查手机视口。CLI 区分了 Orbit 的固定、错速与释放，以及 Folio 的静态编号目录，提出“对版—压印—揭纸”的叙事，用目录查开放日信息。该次请求只要方案。 |
| 现有设计增强 | 在已有 Moonfall Ark 前端（基线提交 `8d4639a`）的隔离副本上运行首页。先观察月面、月怒和窄屏，再只改沙盘组件。桌面前后导航、首屏文案、沙盘、状态切换与数据段的边界一致。新信号沿月面扩散约 1.1 秒；停留、重复点击都不重播，离开后再进入会重新播放。测试发现运行中切换减弱动态偏好有遗漏，已在副本修正并用真实按钮复测，开启减弱动态后再次进入月怒不播放信号。 |
| 复杂滚动 | 从 Orbit 中提取固定和错速机制，生成原创双色套印原型。Chrome 中点青版为 81%、朱版为 54%，末段均为 100%，反向滚动回到 0%。验证释放、模拟触屏、键盘、窄屏和减弱动态。测试者确认原型后，CLI 将机制接入另一份现有说明页；原导航和正文仍可用，桌面与窄屏的介绍区像素对比一致。 |

## 验证边界

测试运行中，CLI 在受限环境无法连接本地预览时如实标记了未验收项；改用可访问预览的环境后，才记录浏览器结果。以上覆盖桌面 Chrome 和移动视口、触屏模拟。尚未在实体手机、Safari、Firefox 或正式部署链路上验证。Moonfall 测试对象是现有前端副本，录音、版画参考与说明页使用测试内容。
